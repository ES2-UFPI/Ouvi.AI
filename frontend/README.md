# Ouvi.AI — Frontend

React + Vite + TypeScript + Tailwind, organizado por feature.

## Estrutura

- `src/app/` — providers, rotas e layout
- `src/features/` — uma pasta por funcionalidade (auth, player, materials...)
- `src/shared/` — componentes e utilitários reutilizáveis entre features

## Desenvolvimento local (sem Docker)

npm install
npm run dev
